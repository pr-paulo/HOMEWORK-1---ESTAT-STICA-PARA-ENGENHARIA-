## HOMEWORK-1

O primeiro Homework trata-se da analise de 300 amostras atreladas ao uso diário de bicicletas em uma cidade dos Estados Unidos. Neste sentido, visando entender a dinâmica entre as varáveis, foram realizadas análises utilizando o R e cáculos teóricos, bem como construídos vários tipos de gráficos que relacionam as variáveis originais com as criadas ao longo da execução da atividade. Por fim, as conclusões foram reunidas num relatório que fundamenta a relevância de cada indicador no contexto do trabalho.

## Tecnologias

Como dito anteriormente, para o desenvolvimento dessa atividade foi utilizado o RStudio para a parte de código do projeto. Além disso, o relatório foi desenvolvido utilizando a plataforma OverLeaf. 
Sobre a execução do código no RStudio, há de se atentar para o fato de que foram utilizados, além dos pacotes nativos do R, os pacotes DescTools, openxlsx.
